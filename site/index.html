AI Agent · 记账

说一句话就记好，
你点确认才入账。

AI 不能直接改你的账本。它只生成一张草稿卡片，分类、账户、日期都替你填好，你看一眼没问题再点确认。手快点了两下，也只会记成一笔。

  1. 你说昨天在山姆买菜 328，刷的招行信用卡
  2. 它出草稿食品生鲜 / 超市 · 招行信用卡 · 昨天 · ¥328.00
  3. 你确认金额换算和账户校验由后端完成，不靠模型说了算。

AI Agent · 花钱决策

想换手机之前，
先翻一遍自己的账。

问它「iPhone 13 Pro 用了快四年，想换 17 Pro，该换吗」，它会把这些数一次查齐，再给你一句结论：

旧机已用 / 预期寿命
4.02 年 / 4 年
旧机日均持有成本
¥5.51
8999 元占可动用现金
4%
本月预算剩余
¥7,097.24

以上为演示账本中 AI 的真实回答。可接入博查、Tavily 或自建 SearXNG 联网查价。

不做投资顾问，不给股票、基金、保险的买卖建议，只帮你量入为出。

飞书机器人

在飞书里聊着天，
账就记好了。

私聊机器人说「昨天吃饭花了 200 元」，回来一张卡片，点「确认入账」就落库。问「上周支出」，直接给你一张分类柱状图。和网页上是同一个 AI Agent，两边重复点也不会记成两笔。

订阅续费、保单到期、待确认的自动记账也会推到飞书，卡片上的按钮当场就能处理。机器人走长连接，家里的 NAS 不用做端口映射。

家里的钱，常用的都在

Face ID 应用锁

打开就要 Face ID / Touch ID 才能看账，其它设备回退输入密码。在飞书里打开默认免验证。

只选人，不选渠道

提醒配给谁，走飞书还是手机通知由接收人自己决定。一条提醒最多 5 档提前量，处理过一次就不再打扰。

iPhone 收通知

网页添加到主屏幕就能收推送，不需要 Apple 开发者账号，也不用上架。

多人协作

多账本、多成员，邀请码加入、创建者审批。账户可标归属人，净资产能按家里的人分开看。

自动记账

房租、话费配成规则，到期生成一条待确认；常记的账做成快捷模板，一键记账。

数据是你的

Excel 导入导出；整站定时备份成一个 zip，含数据库、附件和每个账本的 Excel，换机器直接传回去恢复。

部署到自己的 NAS

一份 compose 拉起数据库、对象存储、迁移、API、Worker 和网页，对外只开 4001 一个端口。

  • 群晖、威联通、TrueNAS、Portainer 可直接粘贴内联版 compose
  • AI、飞书、推送都是可选项，不配就不出现
  • 模型可接 DeepSeek、通义、OpenAI 或本地 Ollama
# 下载 docker-compose.yml 和 .env.docker.example 到任意空目录
$ cp .env.docker.example .env.docker
# 改掉 POSTGRES_PASSWORD 和 MINIO_SECRET_KEY
$ docker compose --env-file .env.docker up -d
# 打开 http://<你的主机>:4001，第一个注册的人就是管理员
